# Privacy

This repository contains a static skills catalog. Its site has no project-owned account system, upload form, analytics, or application backend.

GitHub Pages hosts the site. GitHub says it logs and stores visitor IP addresses for security purposes. See [GitHub Pages data collection](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) and [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The project owner does not receive a visitor log from this site.

The site does not load an external font service. Following links to GitHub or other sites takes you under those providers' own privacy practices.

The repository and its issues are public. Do not publish confidential work material, personal information, customer data, or credentials here. See SECURITY.md for private reporting guidance.
